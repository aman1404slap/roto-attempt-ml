# v1.3 — the consolidation iteration (final round on the sample drop)

Everything measured so far converges on one conclusion: the model and method are no longer the
bottleneck — the *ground* they stand on is. This iteration rebuilds the ground once, re-baselines
once, closes the deliverable loop, and defines done. After it, the honest next step is scale
(archive subset, held-out shots), not more rungs on six shots.

## 1. The one blocking item: the dataset rebuild (start here, nothing lands before it)

`datasets/v002`, one rebuild clearing every measured debt at once:

- **Interpolation law**: alphas re-rendered under the clamped-CR law (clears the RED ledger row —
  ceiling returns to 1.000000 on all layers, all frames).
- **Render conventions**: `fill_open_zero_width=False`, stroke gain at the measured hairline floor,
  `duplicate` endpoints — the two conventions refereed wrong in v1.1 flip together.
- **Transform representation**: 8-number projective throughout (already in code; the dataset
  inherits it).
- **Split defined at build time**: (a) every-7th-frame holdout as now, and (b) a **held-out-layer
  split** — freeze 2 of the 13 layers (one small, one shape-dense) out of training entirely. Not
  a generalization claim yet (queries are per-layer), but it forces the plumbing every v2
  experiment needs and prices the query-table dependence honestly.
- Ledger green end to end on v002 before any training run. `scripts/ledger.py` gates it.

## 2. The run plan (short, sized by the noise floor)

| run | purpose | seeds |
|---|---|---|
| `v002_control` (v1 config, 40k) | the new baseline; every past number re-anchored once | 2 |
| `v002_final` (headline config, 40k) | the shipping candidate | 2 |
| `final_long` on v001 (backfill) | settles the sqrt-weighting 0.0025 question — cheapest open item | +1 seed |
| `v002_keytime` | **the key-timing head**: per-frame, per-shape key probability supervised by the artist's keys, biasing the DP tolerance locally. The one plateau (key F1 ~0.41) with an untried, well-motivated fix | 2 |

Rules that are now policy: two seeds per quoted number; 40k schedule (3× quieter than 12k);
rank on frames-below-0.90 count, never on the single worst frame; always score the exact
checkpoint intended to ship. Differences under 0.003 at 40k are weather, not results.

The delta-prediction design note (jitter in prediction space) gets written, not coded, this
round — the crop-quantisation objection is on record and unresolved.

## 3. Close the deliverable loop: write a real .sfx and open it

The projective fix made serialisation possible; nothing written has ever met Silhouette. This
round: implement `sfx/write.py` (serialisation only, no ML), round-trip it through our own reader
(ledger row: read(write(IR)) bit-exact), and validate ONE file in an actual Silhouette seat —
renders identical, shapes selectable, keys editable. This needs the license; it is the last
external dependency on the zero-margin claim and should be re-raised with Jon now.

## 4. Acceptance gates — what "as good as v1.x can be" means

On v002, headline config, 2-seed mean, all through the constrained operating point and with
predicted motion end to end (no teacher-forced transform):

- soft IoU ≥ 0.97 mean; every layer ≥ 0.90; frames below 0.90 ≤ 1% per layer
- point error ≤ 1.2 px mean, p95 ≤ 3 px (256 crop)
- keys within [0.75, 1.30]× artist; key F1 ≥ 0.42 (keytime head's target: ≥ 0.50)
- held-out-frame gap ≤ 0.002; scoring ceiling = 1.000000 (post-rebuild)
- one .sfx opened, rendered, and edited in Silhouette with no manual repair

Gates met → declare reconstruction on the sample drop done and stop polishing it. Gates missed →
the failing gate names the next rung; nothing else gets added.

## 5. After the gates: the scale phase (v2 proper)

Archive subset ingest (pairing QC as a gate — the sh0230 detector runs on every shot), dataset
v003 with held-out **shots**, dynamic queries derived from the matte (the memorisation-to-
generalisation jump, ablated against the frozen v002 baseline), and the move to approved cloud
GPUs — for data governance and seeds-parallelism (three 40k seeds: 46 min serial locally, one
18-min wall on three instances), sized at one A10G/L4-class card per run.

## 6. Standing risks on the record

Stroke geometry validated only against delivered EXRs, not inside Silhouette (closed by §3);
key F1 target values are set by judgment, not by artist study — when a seat exists, one artist
hour reviewing a reconstructed file is worth more than another metric; generalization remains
unclaimed until held-out shots exist (by design, stated in every report so far).
